# ANGAR PRO — Ангары и металлоконструкции

Современный веб-дашборд для компании, занимающейся проектированием и строительством промышленных ангаров и металлоконструкций.

## 🎨 Особенности

- **Киберпанк дизайн** — неоновый стиль с cyan и orange цветами
- **Анимированный фон** — Tron-подобная сетка с движущимся городом
- **Адаптивный дизайн** — отлично выглядит на всех устройствах
- **Гладкие анимации** — появления, переходы, shimmer-эффекты
- **Интерактивные элементы** — карточки услуг, проекты, галерея
- **Доступность** — поддержка уменьшенной анимации (prefers-reduced-motion)

## 📋 Разделы

1. **Hero** — главный экран с предложением
2. **Услуги** — 6 основных направлений деятельности
3. **Проекты** — примеры реализованных объектов
4. **Галерея** — портфолио с 12 объектами
5. **Контакты** — информация для связи и соцсети

## 🛠️ Технологии

- HTML5
- CSS3 (Grid, Flexbox, clip-path, animations)
- Canvas API (анимированный фон)
- Vanilla JavaScript (никаких зависимостей!)

## 📱 Размеры экранов

Оптимизирована для:
- 📱 Мобильные телефоны (320px+)
- 📱 Планшеты (768px+)
- 💻 Десктопы (1024px+)

3. Готово! Никаких зависимостей и сборки не требуется
